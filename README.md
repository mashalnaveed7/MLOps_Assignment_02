# MLOps Assignment 02 — Dockerized ML Prediction Service

## Project Overview

This project implements a reproducible machine-learning prediction service using Docker, Docker Compose, DVC, FastAPI, Redis, and Docker Hub.

The service uses the Scikit-learn Breast Cancer dataset to classify samples as likely malignant or benign. This is an educational screening-support project, not a medical device.

## Assignment Milestones

- Milestone 0: Docker CLI fundamentals
- Milestone 1: Dataset versioning with DVC
- Milestone 2: Model training, DVC pipeline, and FastAPI service
- Milestone 3: Docker image building and inspection
- Milestone 4: Docker Compose and Redis
- Milestone 5: Docker Hub publishing and clean-room verification

## Project Status

Docker installation and initial container tests have been completed. Implementation of the ML service and remaining milestones is in progress.

## Requirements

- Docker Desktop with the WSL 2 backend
- Python
- Git
- DVC
- Docker Compose v2 or compatible Compose CLI

## Repository Structure

The project will contain the training scripts, API, tests, Dockerfiles, Compose configurations, DVC files, and documentation required by the assignment.
